# 连续漫画滚动稳定性修复与清理计划

## 行为约束

图片异步加载不能改变当前可见内容的屏幕位置；加载期间继续拖动或惯性滑动，保持原有滚动活动。章节进入、窗口追加/裁剪不能强制跳转或重建仍在视口中的图片。目录、页码、音量键等用户主动导航仍然可用。保留原图比例和有界数据窗口，不新增依赖。通常保留当前章前后缓冲；视口跨多章时保留可见章节区间及前后各一章，避免裁掉仍可见内容。

## 已定位的问题

- 图片高度由占位比例变为真实比例，缺少布局阶段的位置保持。
- `_presented` / `_userScrolling` 延迟到松手显示图片，只是把高度跳变挪到手势结束；父组件重建还可能提前读到已更改的比例。
- 章节更新用 `jumpTo` 恢复位置，并把负的页内位置截为 0，丢失长图阅读位置、打断手势。
- 旧索引列表按窗口内数字索引保留元素，裁剪前章后会重挂载可见图片。

## 执行顺序

1. 补充延迟图片、拖动续行、惯性、章节窗口变更的像素位置回归，先确认旧实现失败。
2. 以稳定的章节/页标识保留元素，使用 Flutter 原生惰性列表与布局阶段滚动位置修正；窗口及图片高度变更统一保持当前内容位置。
3. 删除松手后集中显示、章节恢复强制跳转及对应冗余状态。占位、失败、重试使用同一页面尺寸契约。
4. 邻章预取继续复用现有源缓存；不等待手势结束才准备窗口。限制数据和尺寸缓存范围。
5. 独立运行漫画阅读器测试、静态分析、格式和 diff 检查；独立审查。设备性能验证与 widget 正确性证据分开报告。

## 兼容路径分类

未知图片比例的临时占位是必要加载状态，需通过位置保持消除副作用；原生 ImageDescriptor / Web codec 差异有真实平台依据，继续保留。松手延迟显示和强制跳转属于掩盖布局问题的补偿，删除。其他并行任务文件不在范围内。

## 实现与审查

- 原生 ListView.itemExtentBuilder 统一图片、占位、错误态的高度，稳定章节/页 key 和 findChildIndexCallback 保留可见页面实例。
- ComicScrollController 维护页标识和高度前缀，在 applyViewportDimension 内一次消费位置修正。修正发生在列表选择/回收子元素之前，不调用 jumpTo/animateTo；标准 applyNewDimensions 延续拖动或当前惯性速度。
- 可见的上一张占位图变化时保留下一张正在看的页面；上方页批量变化合并为一次几何修正。完全未知的当前长图像素无法提前知道，保留已经可见的内容边界。
- 邻章前两页复用源缓存预取，同时准备真实尺寸和 Flutter 图片解码缓存。
- 删除延迟显示标志、滚动监听开关、章节跳转补偿、子组件重复尺寸状态及错误态固定高度；用户主动导航继续使用导航 API。
- 独立审查指出异步换窗时反向滑动可能裁掉右侧可见章、提前预取可能删掉左侧缓冲；已统一保留双向可见区间和已有相邻章。章节标题的 key 不再随窗口首章变化而消失。
