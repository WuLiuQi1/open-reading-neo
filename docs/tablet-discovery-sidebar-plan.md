# 平板发现页侧栏优化

## 问题与目标

用户截图显示全部/收藏/分组、书源与分类都堆在横向胶囊中，内容起点过低。标准发现布局改为左侧书源导航、右侧分类与书籍，保留已验收的顶部悬浮导航、高斯模糊及统一边界。

## 实施边界

- 复用现有发现控制器、缓存、收藏与分组动作，不改变请求策略或同步/书源导入等并行修改。
- 平板标准布局在容得下侧栏和至少360dp内容区时使用双栏；侧栏宽240dp并随字号适度增加，栏间24dp，外框1200dp、左右28dp。窄窗和大字号按可用空间回退，手机及现有目录布局保持各自路径。
- 侧栏使用纵向全部/收藏/分组入口、本地书源搜索与惰性来源列表，独立滚动。右侧保留推荐/分类/最新切换、来源动作和分类选择，书籍网格按实际右栏宽度分列，内容可滚入顶部高斯过滤区。
- 简化：从平板主区移出重复的组织和书源横向选择条；继续复用主区加载、错误、空态和分页组件，只统一主区padding与网格宽度计算。

## 验证计划

先调整现有平板坐标测试并新增侧栏交互测试，记录未实现时失败；然后实现并串行运行独立状态化测试进程。检查书源切换、收藏、分组、本地搜索、独立滚动、手机/窄窗/大字号回退。截图覆盖横屏、竖屏、深色与有书籍的真实Flutter页面，复核顶部和两栏边界。完成全项目静态分析与差异检查；实体平板触控和帧率另行验证。

## 实现与验证结果

- `book_sources_page_tablet.dart`负责平板双栏组织与组织范围入口；`book_source_tablet_sidebar.dart`负责独立的书源搜索、惰性列表与滚动。主页面继续使用原控制器及结果组件。
- `book_sources_page_list_content.dart`按实际右栏宽度计算1至3列，大字号改用自然高度列表；聚合分类保留书源归属，避免收藏/更多操作的对象不明确。
- 768dp窗口侧栏240dp、右栏448dp；1366dp窗口中外框1200dp，侧栏左边111dp，右栏左边375dp、宽880dp。两栏间距24dp，左右内边距28dp。
- 先记录缺少侧栏的失败后，新增侧栏交互及现有平板布局测试均通过。覆盖来源、收藏、分组、本地搜索、主区恢复顶部、聚合分类来源、旋转和目录模式边界。
- 原有手机范围切换、阅读书源分类和目录展开选频道测试各自独立进程通过。预览测试覆盖横屏、竖屏、深色、600dp紧凑窗口、3倍字号分类与键盘压缩，并验证侧栏滚动不改变右侧偏移。
- 全项目静态分析与差异检查通过。预览由真实发现页组件和离线示例数据生成，预览外壳仅包含标题与渐变背景；应用完整悬浮导航沿用现有实现。未构建安装包或测量实体平板触控/帧率。
